
1) Add the official STM32 Boards library (STM32duino) to the ArduinoIDE
   File-> Preferences -> Add the URL to the Additional Boards Manager 
   URLs: https://github.com/stm32duino/BoardManagerFiles/raw/main/package_stmicroelectronics_index.json

2) Add OpenFFBoard variant files to the folder below:
   ...\STM32\hardware\stm32\<version>\variants\STM32F4xx\F407V(E-G)T_F417V(E-G)T\
       └── variant_OpenFFBoard_F407VG.h
	   └── variant_OpenFFBoard_F407VG.cpp

3) Add the OpenFFBoard variant to the Boards.txt located here:
   ...\STM32\hardware\stm32\<version>\boards.txt

    In the GenF4 section of the boards.txt insert the data below (Example showing location following: 

    ▼▼ Add This ▼▼

4) ArduinoIDE Board Configuration
   * Tools -> Board -> STM32 MCU Based Boards = Generic STM32F4 Series
   *           Board Part Number: OpenFFBoard_F407VG
   * Debug Symbols and Core Logs: Symbols Enabled (-g)
   *                    Optimize: Smallest (-Os Default
   *           C Runtime Library: Newlib Nano + Float Printf
   *               Upload Method: STM32CubeProgrammer (DFU)
   *  USB Support (if available): CDC (Generic 'Serial' supersede U(S)ART)
   *                              HID (keyboard mouse)
   *  	         U(S)ART Support: Enabled (generic 'Serial')
   *                   USB Speed: Low/Full Speed
